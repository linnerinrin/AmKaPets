# ka-am-pet

Windows 桌宠：心情贴图、点击互动、拖拽甩抛、多宠物碰撞、OpenAI 兼容对话，
支持 overlay / desktop 两种模式，最终打包为桌面 EXE 双击即用。

默认宠物：超天酱（kangel）与糖糖（ame），心情系统四档（happy/smile/sad/angry）实时切换贴图。

## 实例系统与托盘

- 首次启动弹出**启动器**：勾选本次要运行的实例（可多选、可多开同角色）。
- 实例 = 基底角色（kangel/ame）+ 自定义名字 + 尺寸 + 独立人格提示词，存 SQLite：
  `%APPDATA%\ka-am-pet\pets.db`，长期保存，退出时记住各自最后位置。
- 每个实例的对话记忆按实例 id 隔离（`memory.json` 分组），提示词就是该实例设置里的「系统提示词」，
  对话时再追加当前心情提示词。
- **配置全在实例设置里**（没有「跟随全局」了）：右键宠物 →「实例设置…」（或托盘菜单里该实例的「实例设置…」），
  三页 —— 信息（桌宠类型/名字/尺寸/覆盖模式 + 「当前状态」卡片区）、聊天（Base URL / API Key / 模型 /
  系统提示词 / 记忆轮数 / 超时 + 「历史会话」只读列表）、交互（物理 / 摸头 / 拖拽 / 飞行 / 摇摆 五个并列模块）。
  好感数值是写死的常量，界面上只展示、不给改。同一台机器上可以一只用 A 家模型、另一只用 B 家。
- **👁 覆盖模式**：每只宠物左上角有一个眼睛按钮（镜像转身后会跟着滑到右侧），点一下切换「覆盖模式」——
  开启后这只宠物只看得见、点不到（鼠标穿透），不再挡桌面操作；再点一下恢复。托盘/右键菜单里也有同名开关可救急。
- 程序托管到**系统托盘**：右击托盘图标 = 实例列表（逐只对话/实例设置/覆盖模式/移除）+ 新增实例… +
  让她们摇摆一下 + UI 设置… + 退出。宠物右键只保留 对话 / 实例设置… / 覆盖模式 / 退出。

## 目录结构

```text
ka_am_pet/        # 主包（ui/ 为唯一依赖 PySide6 的层）
  physics.py      # 甩抛物理（纯 Python）
  collision.py    # 多宠物碰撞（纯 Python）
  mood.py         # 心情系统（纯 Python）
  db.py           # 实例库 SQLite（纯 Python）
  audio.py        # 系统音频峰值检测 + 音乐律动状态机（纯 Python + ctypes）
  animation.py    # 帧动画 manifest 与状态机（纯 Python）
  characters.py   # 基底角色目录与显示名
  world.py        # PetWorld 统一物理世界 + 每实例生效设置解析
  config.py       # 配置加载/校验/原子保存
  models.py       # 配置/物理/心情/音乐/覆盖组数据模型
  actions.py      # 抽象动作表（点头/左右摇摆/摸头，点击池与摸头池共用）
  theme.py        # 主题色抽象（预设 + 自定义，各样式表生成）
  services/       # OpenAI 对话 / 记忆持久化（纯 Python）
  ui/             # overlay / desktop / 启动器 / 对话 / 设置 / 查看状态(面板+气泡) / 侧边栏骨架
                  # 其中 ui/fields.py 是主题化输入控件：QSS 描边后 Qt 会把 spin 箭头和
                  # combo 下拉框画成残缺的「⌐」L 形，所以上下按钮/下拉区改成透明、箭头自绘
assets/pets/      # {pet}-{mood}.png 心情贴图（640×640 透明底）
tests/            # pytest 测试
```

## 玩法

- **单击**宠物（desktop 模式）：进入「查看状态」——桌宠上方贴出 150~200px 的小状态卡
  （名字、好感进度条、档位、音乐状态），底部有一条输入框，发的消息由桌宠用**气泡**回复
  （气泡颜色 = 主题色1，点一下气泡收掉）。再单击同一只、点击面板之外、或开始拖拽/甩飞/双击等
  其它互动时，查看状态立刻退出。单击同时随机播放「点头摇摆」或「左右摇摆」（**单击不加好感**）。
- **双击**宠物：摸头——按两次点击的时间间隔判定（间隔超过系统双击时间就算两次单击），
  触发后按该实例的「摸头动作池」随机抽一个动作播（默认只勾「点头摇摆」），并按固定区间 [0, 2] 加好感，
  摸头有独立冷却（冷却 = 最长动作时长）。
- **overlay 模式**：桌宠只读展示——不可点击/拖拽/查看状态，唯一可点的是左上角的**眼睛按钮**
  （矢量绘制的眼睛图标，非 emoji），用来切换覆盖模式。
- **覆盖模式**（👁）：该宠物只看得见、点不到（鼠标穿透到下面的应用），镜像转身后眼睛跟着滑到另一侧。
- **拖拽**：跟手弹簧；快速松手甩出抛物线，撞墙反弹、落地摩擦直到停下。拖拽与飞行各按每秒掷一次
  好感（固定 [0, 2] 区间）。**松手/落地时会飘一次结算飘字**：`提起 +3 → 83`、`飞行 +6 → 85`
  （增量为 0 时不显示）。
- 宠物走到屏幕左半边会自动镜像转身（压扁→换向→展开动画）。
- **右键**宠物：菜单（对话 / 实例设置… / 覆盖模式 / 退出）；实例增删、运行模式与主题都在托盘菜单里。
- 两只宠物同屏时可互相撞飞（动量守恒，质量 = size²）。
- **音乐律动**：系统连续放歌 20~60 秒后才进入音乐模式（越久越容易，概率线性增长；停下约 4 秒退出），
  之后按各实例设定的频率摇摆 —— 默认「点头摇摆」（Q 弹拉伸），也可在设置里换成「左右摇摆」（镜像翻转成对往返，必定回到原位）；飘「♪」提示。

## 设置窗口

设置窗口共用同一套**主题化侧边栏骨架**：自绘标题栏（可拖动，只有最小化/关闭）、
左侧导航（底色 = 主题色1，选中 = 主题色2）、右侧内容背景 = 主题色2 本体；
选项按内容定宽（min/max 成对、短字段合并同一行），界面上不放任何批注式小字。

**实例设置…**（托盘或宠物右键）三页，所有配置按实例保存：

- **信息**：桌宠类型 / 名字 / 尺寸 / 覆盖模式，下面是「当前状态」卡片区 —— 目前渲染「好感度」卡片：
  进度条 + 档位 + 「每秒 -0.1（固定）」+ **直播练习**按钮（开启后心情钉在 100 且不下降，关掉立刻回到进入前的值）。
  卡片区是 `StatusCard` 基类 + `StatusCardFrame` 容器，后续加新状态卡片只需新增一个子类。
- **聊天**：Base URL / API Key / 模型 / 系统提示词 / 记忆轮数 / 超时；下面是「历史会话」只读列表
  （顶部「共 N 条」，每行 `角色 · 时间  内容`）。
- **交互**：物理（重力、弹性、地面摩擦、甩抛力度、顶部反弹、宠物碰撞）、摸头（动作池多选 + 好感消耗
  `+0~2 / 每次`）、拖拽（`+0~2 / 秒`）、飞行（`+0~2 / 秒`）、摇摆（启用、间隔、动作池多选）。
  好感消耗只展示不可改 —— 数值是写死常量。

**UI 设置…**（托盘）只剩整机形态三项：运行模式、覆盖层透明度、主题（预设「淡蓝/白」等 5 套或自定义两个色）。

## 心情系统

好感（心情）0–100，初始 80，随时间下降 **0.1/s（写死，约 13 分钟从 80 掉光）**。四档区间：
`[75,100]=happy`、`[50,74]=smile`、`[25,49]=sad`、`[0,24]=angry`。
好感增减都是**整数区间随机、且全部写死**：摸头 `[0,2]`（单击不加好感），拖拽与飞行各 `[0,2]/秒`（每秒掷一次）；
摸头动作池默认只勾「点头摇摆」，可在实例设置里多选；摸头有独立冷却（冷却 = 最长动作时长）。
档位实时切换贴图，并在对话时追加心情提示词。
**直播练习**：在「当前状态 → 好感度」卡片里开启后，心情恒为 100 且不下降，关掉恢复进入前的值。
飘字已去掉白色底块，只保留深色描边 + 粉字，且淡出后一定会立刻重绘清掉（不会在头顶留下透明残影）。

## 音乐律动

通过 Windows Core Audio 读取默认输出设备的实时峰值（`IAudioMeterInformation`，纯 ctypes，不引入 pycaw 等第三方库）：
峰值高于门限即判定"在响"（滞回判定，短暂安静不会闪断），连续 3 次安静采样后停止。
「持续多久才算音乐模式」由 `audio.MusicGate` 管：连续播放不足 20 秒不会触发；之后每 2 秒按
`p = (已连续秒数 - 20) / 40` 掷一次骰，满 60 秒必定进入；音乐停下超过 4 秒才退出。因此看视频、开语音也不会一有声音就摇。

摇摆开关、动作与频率都在实例设置的「交互 → 摇摆」里调（每只实例各自选择要不要律动）：

- **摇摆动作（可多选）**：默认三个动作全勾 = 每次随机播一个。勾选列表里勾几个就只在几个里随机：
  「点头摇摆」是 Q 弹拉伸；「左右摇摆」复用越中线时的镜像翻转动画（翻转次数为偶数，结束时必定回到原朝向，
  镜像后眼睛按钮自动跟着滑到另一侧）；「摸头」是压扁回弹。只勾一个就等于固定播放该动作。
- **摇摆间隔**：下限 0.5 秒（约每秒两次，飘字允许重叠叠放），上限 10.0 秒，默认 1.5 秒；每只实例可各调各的。

## 配置

首次启动生成 `%APPDATA%\ka-am-pet\config.json`（整机形态：模式/透明度/主题 + 宠物列表 + 新建实例的默认值）。
**好感数值在配置里已不再生效**（第四轮起全部写死：初始 80、下降 0.1/s、三个区间都是 `[0,2]`），
写什么都不影响运行；`audio.music_pool` / `theme` 等默认值仍作为新建实例的初值。
实例库 `%APPDATA%\ka-am-pet\pets.db` 里存每个实例的完整设置组（`overrides_json`：物理 / 对话 / 摇摆 / 摸头动作池）
与覆盖模式标记 —— 不再有「空组 = 跟随全局」的语义。
对话记忆存 `%APPDATA%\ka-am-pet\memory.json`，全量保存，只截取最近 N 轮发给模型。

### 数据目录写不进去时

如果 `%APPDATA%\ka-am-pet` 不可写（常见于在沙箱/受限终端里启动，或目录权限被改过），
程序不会崩，而是按顺序退到下一个可写目录，并用弹窗说明备用目录：

1. 环境变量 `KA_AM_PET_DATA_DIR` 指定的目录（最高优先级，想固定位置就设它）；
2. `%APPDATA%\ka-am-pet`；
3. `%LOCALAPPDATA%\ka-am-pet`；
4. 源码运行时项目内的 `.userdata`（已 gitignore）；
5. `%TEMP%\ka-am-pet`。

降级时会尽量把原来的 `config.json` / `pets.db` / `memory.json` 复制过去，旧实例不丢。
如果实例库本身是「只读」属性，程序会先尝试就地去掉只读位并继续用原库；
实在改不动才复制到可写目录继续跑（原库保持不动）。
想回到 `%APPDATA%` 只需恢复该目录写权限，然后删掉备用目录里的数据再启动。

## API 设置

在设置窗口填写 OpenAI 兼容服务的 `base_url` / `api_key` / `model`；
请求 `POST {base_url}/chat/completions`。API Key 以密码形式输入，不写入日志。

## 模式切换

- **overlay**：单一大窗口承载全部宠物，可调整体透明度；桌宠只读展示（不可点击/拖拽/查看状态），
  只有左上角眼睛按钮可点来切覆盖模式，其余区域鼠标穿透。
- **desktop**：每只宠物一个独立窗口，共享同一物理世界；单击进入查看状态，双击摸头。
切换无需重启，位置/速度/记忆保留。

## 常见故障

- **双击无窗口/缺 DLL**：确认使用打包后的 EXE；开发运行需先装 requirements-dev.txt。
- **对话报错**：检查 base_url 是否需要翻墙、api_key 是否有效、模型名是否正确。
- **pip 安装卡住**：系统代理失效导致，先 `$env:NO_PROXY="*"` 再安装。
